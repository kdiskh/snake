# Игра "Змейка" на Python 

Мой первый проект, написанный на Python с использованием библиотеки Pygame.

## Как играть
* Управление: стрелки на клавиатуре (влево, вправо, вверх, вниз).
* Пауза: клавиша `0` (ноль).
* Цель: собирать красные яблоки и не врезаться в стены или свой хвост.

## Как запустить
1. Скачайте файлы из этого репозитория.
2. Установите библиотеку: `pip install pygame-ce`.
3. Запустите файл `snake.py`.
